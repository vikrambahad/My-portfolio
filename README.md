# Vikram Bahad — My Portfolio

## Direct GitHub upload

Upload the files from this package directly into the ROOT of your GitHub repository.

Root files:
- index.html
- style.css
- script.js
- database.sql
- README.md
- LICENSE
- .nojekyll
- assets/

Important: `index.html` already uses `./style.css` and `./script.js`.
Do NOT put these two files inside `css/` or `js/` folders.

For GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root).

`database.sql` is for a separate MySQL/backend setup. GitHub Pages is static.
